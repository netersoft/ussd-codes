Politique de confidentialité

En vigueur au 6 octobre 2026.

Codes USSD est un catalogue des codes USSD des opérateurs mobiles, édité par Netersoft. Cette politique explique ce que l'application fait de vos données : elle les garde sur votre appareil.

Aucune donnée collectée

Codes USSD ne collecte, ne transmet et ne vend aucune donnée personnelle. L'application n'a pas de compte utilisateur, n'affiche pas de publicité, ne contient aucun outil de statistiques d'usage ou de suivi des plantages actif, et n'envoie aucune donnée à Netersoft.

Données enregistrées sur votre appareil

  • Vos favoris et vos codes personnels restent sur votre appareil. Si l'ancienne version de l'application était installée, ses codes personnels et favoris sont repris au premier lancement.
  • Vos préférences (thème, langue, pays choisi, appel direct) sont enregistrées sur l'appareil, ainsi que la date de première ouverture et le nombre de lancements, qui servent à choisir le moment où proposer de noter l'application.
  • Les valeurs que vous saisissez dans un code (numéro, montant…) servent uniquement à le composer et ne sont pas conservées.

Désinstaller l'application supprime définitivement ces données.

Exécution des codes et autorisation Téléphone

Sur Android, quand l'option « Lancer l'appel directement » est activée, l'application demande l'autorisation Téléphone au premier code exécuté, puis compose le code directement. Si vous refusez ou désactivez l'option, le code s'affiche dans le composeur et c'est vous qui lancez l'appel. Sur iOS, le code est copié dans le presse-papiers pour que vous le colliez dans le composeur.

Un code USSD est traité par votre opérateur, comme si vous le tapiez vous-même. Sur Android 8 et plus, en mode direct, l'application affiche la réponse de l'opérateur. Cette réponse reste sur l'appareil : elle n'est ni enregistrée ni transmise. Dans les autres cas, la réponse est affichée par le système et l'application ne la lit pas.

Contacts

Sur Android, pour remplir un numéro dans un code, vous pouvez choisir un contact dans le sélecteur de contacts du système. L'application reçoit seulement le numéro choisi : elle ne demande pas l'autorisation Contacts et n'accède pas au reste de vos contacts. Ce numéro sert uniquement à composer le code et n'est pas conservé.

Carte SIM et pays

Sur Android, l'application lit l'opérateur de vos cartes SIM et le pays du réseau mobile pour présélectionner votre pays et vos opérateurs dans le catalogue. Ces informations sont utilisées sur l'appareil et ne sont jamais transmises. Elles ne nécessitent aucune autorisation supplémentaire.

Mise à jour du catalogue

Pour recevoir les nouveaux codes et corrections sans mise à jour de l'application, Codes USSD télécharge au plus deux fois par jour le catalogue public publié sur netersoft.github.io, ou quand vous le demandez dans les réglages. Cette requête n'envoie aucune donnée vous concernant. Comme pour toute page web, l'hébergeur GitHub reçoit l'adresse IP de l'appareil ; voir la déclaration de confidentialité de GitHub. Sans connexion, l'application fonctionne avec le catalogue déjà présent.

Partage, avis et contact

Quand vous partagez un code ou l'application, le menu de partage du système ou l'application choisie (WhatsApp, e-mail, SMS) s'ouvre : vous décidez à qui envoyer le message. Pour suggérer un code ou une correction, l'application ouvre votre messagerie avec un e-mail prérempli que vous pouvez relire avant de l'envoyer. Sur Android, elle peut afficher la fenêtre d'avis de Google Play, gérée par Google : l'application ne sait pas si vous avez noté ni ce que vous avez écrit.

Enfants

Codes USSD ne collectant aucune donnée, elle ne collecte pas non plus de données d'enfants.

Modifications

Si cette politique change, la nouvelle version sera incluse dans la mise à jour de l'application, avec sa date d'entrée en vigueur.

Contact

Pour toute question sur cette politique ou sur l'application, écrivez à support.netersoft@gmail.com.
